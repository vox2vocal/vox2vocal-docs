# Voice Analysis Engine

## 목적

Voice Analysis Engine은 입력 음성의 발화 특성을 분석한다. 말의 내용뿐 아니라 억양, 강세, 에너지, 말 빠르기, 호흡 패턴을 추출해 이후 보컬 변환의 표현 재료로 제공한다.

## 입력

- 표준화된 오디오
- 발화 구간 타임스탬프
- 선택 입력: 텍스트, 언어 코드, 사용자 프로필

## 출력

- 에너지 곡선
- 발화 속도
- 강세 후보
- 호흡 및 휴지 구간
- 억양 흐름 요약
- 감정 또는 표현 태그 후보

## 주요 기능

- 음성 에너지 분석
- 발화 구간별 속도 측정
- 강세 위치 탐지
- 호흡/휴지 구간 탐지
- 말투 기반 표현 힌트 생성

## MVP 범위

- 에너지 RMS 곡선 추출
- 발화 속도 추정
- 휴지 구간 탐지
- 강세 후보 타임스탬프 생성
